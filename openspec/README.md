# openspec/

Esta carpeta contiene el historial de proceso spec-driven usado para diseñar e
implementar cambios grandes del proyecto (propuesta → diseño → tareas →
verificación → archivo). El framework es [OpenSpec](https://github.com/Fission-AI/OpenSpec).

Es documentación **histórica y de proceso interno**, no un requisito para
contribuir. Si querés mandar un PR, no hace falta que sigas este formato — ver
[CONTRIBUTING.md](../CONTRIBUTING.md) para el flujo real de contribución.
